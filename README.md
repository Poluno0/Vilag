# Управление жителями (Forge 1.20.1)


Русские команды (требуется OP/уровень прав 2):
- `/villagers запретить` — запрещает появление новых жителей и зомби-жителей. Уже сохранённые жители не блокируются.
- `/villagers убить` — удаляет жителей и зомби-жителей во всех загруженных чанках всех измерений.
- `/villagers разрешить` — вновь разрешает спавн.
- `/villagers статус` — показывает текущий режим.

Состояние запрета сохраняется в данных мира и переживает перезапуск.

## Сборка
1. Установи JDK 17 и Gradle (или импортируй проект в IntelliJ IDEA).
2. Открой папку проекта и запусти `gradlew build` (если Gradle wrapper отсутствует, используй установленный Gradle 8.1+).
3. Готовый jar появится в `build/libs/`.
4. Положи jar в `mods` Forge 1.20.1.
