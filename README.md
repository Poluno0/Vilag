# VillagerControl (Forge 1.20.1)

Команды (оператор):
- `/villagers запретить` — блокировать только новых обычных жителей.
- `/villagers убить` — удалить обычных жителей из загруженных сущностей всех измерений.
- `/villagers разрешить` — снова разрешить спавн обычных жителей.
- `/villagers статус` — посмотреть режим спавна.

Зомби-жители не запрещены. Если попытка лечения должна превратить зомби-жителя в обычного, превращение отменяется, а зомби-житель погибает.


Сборка в GitHub Actions: вкладка Actions, workflow `Build VillagerControl`; артефакт JAR появится после успешного выполнения.
